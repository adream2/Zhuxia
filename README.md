# 驻匣（Zhuxia）

Windows 桌面常驻小工具集合：一个后台进程提供系统监视、剪贴板、截图、手势、录屏、图片转换、图标提取与图床。

## 项目定位

把高频的桌面小工具收进一个低占用的常驻进程，避免为每个功能单独安装一套后台程序。常驻部分使用纯 Win32 + GDI+；设置面板按需启动，关闭即退出，不长期占用 WebView2。

## 核心功能

- **任务栏系统监视**：CPU、内存、磁盘、GPU、网络的实时数值与详情，支持任务栏条/悬浮卡片、多屏与项目排序。
- **剪贴板历史**：文本、富文本、图片、文件采集，去重合并、搜索、收藏、标签与粘贴回填。
- **截图与贴图**：选区/窗口/全屏、标注、美化、拼接、长截图、OCR、贴图置顶。
- **鼠标手势**：8 方向、多笔组合、按程序分组、滚轮修饰、边缘滚动、按键回显。
- **录屏 / GIF**：框选即录，支持 GIF 与 MP4、摄像头画中画/并排、麦克风与系统声音。
- **图片格式转换**：资源管理器右键就地转 JPG / PNG / WebP / GIF / BMP / TIFF / ICO。
- **图标提取**：从 exe / dll / lnk / msi / msix / apk / aab / ipa / app / dmg / icns / deb / rpm / AppImage 提取 PNG / ICO / 全尺寸图集。
- **多平台图床**：GitHub、S3 兼容、WebDAV、自定义 HTTP；上传、浏览、历史与链接复制。

## 作用

- 常看系统状态：任务栏直接显示关键指标，不用常开任务管理器。
- 高频内容处理：截图、标注、贴图、录屏、剪贴板回填、格式转换、图标提取在一个入口完成。
- 减少后台数量：一套常驻进程替代多个独立小工具，空闲时只保留原生绘制与采样线程。

## 适用人群

- Windows 10 / 11 用户，尤其是开发者、运维、设计/办公等频繁截图与复制粘贴的人。
- 希望任务栏常驻系统监控，但不想安装大型桌面套件的人。
- 需要本地优先、不依赖云服务的人：截图、剪贴板、转换、图标均在本机完成。
- 不适合 macOS / Linux，或要求“完全零后台进程”的场景。
