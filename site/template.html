三条线，覆盖大部分日常

功能多不是目的。下面这三件事本来就要连着做，中间每一步都在切换工具——把切换去掉，省下的就是时间。

写文档 · 提 Issue

一张报错截图，变成能搜索的文字

  1. Alt+A 框住弹窗元素识别直接锁在对话框上，不用对边
  2. Shift+C 取字换行按原样还原，不会糊成一整段
  3. 点「AI 整理」形近字、断行、缩进一次修好
  4. 上传拿链接图片放图床，链接自动进剪贴板

全程不离开键盘，也不用为了取一段字去开第二个软件。

做教程 · 复现步骤

录一段 GIF，比写十行字清楚

  1. 框一块开始录红框和计时贴在上面，知道在录哪
  2. 停手即出文件GIF 体积可控，MP4 也可选
  3. 贴图对照关键几步钉在屏幕上，一边看一边讲
  4. 直接发链接录完自动进图床

同事点开就懂，不用等你描述"先点左上角那个"。

日常 · 机器状态

不看任务管理器，也知道机器怎样

  1. 任务栏常驻CPU / 内存 / 磁盘 / GPU / 网速压成两行
  2. 点开看趋势最近 30 秒的曲线，判断是偶发还是持续
  3. 右键划一下切窗口、关标签，不用找菜单
  4. 剪贴板兜底早上复制的那段 SQL 还在

常驻部分只做采样和绘制，不常驻 WebView，闲时几乎不占 CPU。

八件事，一个进程

每个模块都能单独开关；不开的模块不占线程、不占内存。常驻部分只有采样与绘制，设置面板按需启动。
