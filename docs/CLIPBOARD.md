# 剪贴板历史（clipboard）

## 功能

- 采集文本、富文本（RTF/HTML）、图片、文件路径；支持多格式合并。
- 富文本默认开启：Word / 网页 / WPS 复制过来的格式原样保留，可在设置里关掉。
- 按内容哈希去重；重复复制只更新时间与计数，不新增记录。
- 历史搜索、收藏置顶、标签、来源程序过滤。
- 粘贴回填：把选中记录写回剪贴板，并向目标窗口发送粘贴快捷键。
- 隐私保护：密钥/验证码等敏感内容识别，按程序忽略或只记录不落盘。
- 历史清空（可保留收藏）、附件回收、容量与条数上限。

## 数据流

```text
WM_CLIPBOARDUPDATE
  → 读取剪贴板各格式
  → 归一化（文本/HTML/图片/文件）
  → 哈希去重
  → 隐私规则判定
  → 写历史（DPAPI 密文 + 附件）
  → 通知面板刷新
```

## 存储

```text
<exe>/clipboard/
  history.dat          DPAPI 加密的记录表
  attachments/         持久图片附件
  session/attachments/ 会话图片，启动时清空
```

- 记录字段：类型、正文、HTML/RTF、附件路径、来源程序、时间、使用次数、收藏顺序、标签、哈希。
- 图片写入附件目录，历史只存路径与尺寸，避免把大图塞进单文件。
- 历史与附件都按配置做 GC；删除记录时同步删除无引用附件。

## 粘贴回填

- 先把目标记录写回系统剪贴板（必要时延迟渲染）。
- 恢复目标窗口焦点，用 `SendInput` 发送 `Ctrl+V`；可配置粘贴后是否恢复原剪贴板。
- 富文本优先按目标程序能力降级：HTML → RTF → 纯文本。

## 隐私与安全

- 敏感内容默认不写盘或只保留占位；规则可配置。
- 排除程序列表命中时完全不采集。
- 历史文件用 DPAPI（当前用户）加密，离开该用户账户无法直接读取。
- 日志不记录剪贴板正文与密钥。

## 配置

`settings.yaml → clipboard`：采集开关、最大条数/容量、去重窗口、图片开关、文件开关、
敏感内容策略、排除程序、粘贴快捷键与回填行为。

`takeoverWinV`（接管 Win+V）**不在默认值里替用户决定**：首次启动引导会问一次
「要不要接管 Win+V」，回答写进这一项；之后随时能在「剪贴板 → 接管 Win+V」改。
接管用的是低级键盘钩子，与其它剪贴板工具可能冲突。

## 边界

- 只处理 Windows 标准剪贴板格式；私有格式按纯文本或忽略。
- 受 DRM/安全桌面保护的窗口可能无法读取或回填。
- 大图片受单条与总容量限制，超限时按策略跳过或清理旧记录。
