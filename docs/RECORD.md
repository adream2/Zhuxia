# 录屏 / GIF（record）

## 功能

- 选区录制，支持 MP4（H.264）与 GIF 两种输出。
- 帧率、质量、长边、鼠标指针、录制倒计时可配置。
- 摄像头画中画/并排合成，位置、大小、圆角、镜像可调。
- 音频：系统声音（loopback）、麦克风、两者混音；可静音麦克风。
- 录制控制条：暂停/继续、完成、丢弃、计时与文件大小。
- 热键 `Ctrl+Shift+R`；截图工具条提供「录屏」与「录 GIF」两个入口。

## 管线

```text
选区
  → 抓屏线程（DXGI 桌面复制，GDI 兜底）
  → 合成线程（屏幕 + 摄像头 + 鼠标指针）
  → 编码线程（GIF / MP4）
  → 音频线程（WASAPI loopback + 麦克风）──→ MP4 混流
  → 控制条（UI 线程）
```

- 抓屏与编码解耦：抓屏按节拍取“最新一帧”，编码慢时丢帧而不是排队。
- 摄像头只保留最新帧，不排队，避免长时间录制后画面延迟累积。
- 音频按墙上时钟推进，系统静音时也持续写静音样本，保证音画同步。

## 技术路线

- 抓屏：优先 DXGI Desktop Duplication，失败回退 GDI `BitBlt`；GIF 跳过未变化帧。
- 合成：CPU 像素缓冲叠加摄像头与光标，支持画中画/并排布局。
- GIF：中位切分量化 + 脏矩形 + LZW，按帧延迟写入。
- MP4：Media Foundation `SinkWriter`，视频 H.264、音频 AAC。
- 音频：WASAPI loopback + 麦克风采集，PCM 混音后送 MP4。
- 控制条：独立无边框置顶窗口，自绘按钮与计时。

## 文件

```text
<录屏目录>/录屏_yyyyMMdd_HHmmss.mp4
<录屏目录>/录屏_yyyyMMdd_HHmmss.gif
```

已存在时自动加序号，不覆盖；完成/丢弃后释放抓屏与编码资源。

## 边界

- 受 DRM/安全桌面保护的窗口可能录黑。
- 高帧率受抓屏、合成、编码三段耗时限制；4K 高帧率需要更强硬件。
- GIF 无音轨，颜色数受量化限制；长录制建议用 MP4。
- 摄像头与麦克风依赖系统设备；被其他程序独占时可能打开失败。
