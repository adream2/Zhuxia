# 驻匣：一个 13 MB 的 exe，替我关掉了托盘里的八个图标
> 摘要：驻匣（Zhuxia）是一个 Windows 常驻小工具：一个 13 MB 的免安装 exe，集成任务栏监视、流量管理、截图标注与文字识别、剪贴板历史、鼠标手势、录屏、图片转换、图标提取和多平台图床。免费开源，大部分功能不联网。

## 为什么做这个

有段时间我的托盘里挤着一排图标：截图工具、剪贴板历史、鼠标手势、流量监控、图床客户端、格式转换、取图标的……单看每个都不大，但每个都要安装、都要常驻、都要开机自启、都各自弹更新。真正的问题不是那点内存，是**它们互不认识**：截图工具不知道我刚复制了什么，图床工具要我把图先存成文件再拖进去，流量监控发现了可疑程序，也没法直接把它拦掉。

而这些操作其实很零碎：一天截图十几次、粘贴几十次、偶尔看一眼谁在跑流量。为这点频率养八个后台进程，不太划算。

所以有了驻匣：**一个后台进程，把高频的桌面小工具收进去**。现在它是我电脑上唯一常驻的小工具。

## 它是什么

一个单文件 exe，13 MB，压缩包 5 MB，免安装——解压到任意目录，双击就能跑。配置、日志、剪贴板数据都写在 exe 同目录，不往系统目录里塞东西，卸载就是删掉文件夹。

常驻部分的界面全部由程序自己绘制，不加载浏览器内核，所以后台只是一个轻量的进程；设置面板按需启动、关掉即退出，不长期占资源。

八个模块各有独立开关，关掉的模块不装钩子、不起线程、不写数据——不用为了一个功能被迫接受另外七个。

## 任务栏监视与流量管理

这是我最初动手的理由：**别总开任务管理器**。

任务栏上直接显示 CPU、内存、磁盘、GPU 和上下行网速，两种形态可选——贴着任务栏的一条细栏，或者一个可拖动的悬浮卡片，多屏环境下能分别设置显示哪些项目、按什么顺序排。

配套的「流量管理」按进程统计上传和下载。看到某个程序在偷偷跑流量，可以直接把它**加进 Windows 防火墙阻断**，不用再去翻系统自带的防火墙设置。对排查"到底是谁在后台吃流量"这件事，比任务管理器好用得多。

## 截图：从选对区域，到把链接发出去

截图工具很多，所以这里重点做的是"选得准"和"发得快"。

**选区**支持三种：拖动自由框选、单击直接截鼠标下的整个窗口、滚轮在「控件 → 窗口 → 屏幕」之间切换层级。想要整个浏览器就往上滚一层；不想带上它压着的弹窗，就往下滚一层。选区时放大镜跟随鼠标，显示像素坐标和颜色值，右键可以直接把 `#RRGGBB` 复制走。

**标注**有十种工具：选择、矩形、椭圆、箭头、直线、画笔、荧光笔、马赛克、文字、序号。图形画上去了还能再选中、移动、改颜色和粗细，撤销重做都在。

**长截图**（`Ctrl+L`）自动滚动拼接长网页、长聊天记录；**多图拼接**把几张截图按方向叠成一张；**美化**可以加背景（渐变、纯色、截图模糊、透明）、窗口边框、边距、圆角、阴影、水印，还支持固定比例输出，适合直接发社交平台。

**贴图**把截图钉在屏幕最上层——对着参考图抄东西、比对两个界面的时候很有用。

做完的图，`Ctrl+C` 复制、`Ctrl+S` 存盘、或者直接传图床拿链接，不用经历"保存到桌面→打开网页→选择文件"这一套。

## 截图之后的文字：识别、翻译、整理

截图里经常是**不能复制**的文字：报错信息、视频字幕、别人的 PPT、图片里的表格。覆盖层里按 `Ctrl+O` 就能对选区做文字识别，用的是系统自带的 OCR 引擎；想要更高的准确率，可以另外下载离线的增强模型（PaddleOCR），对密集文字和表格效果更好。

识别结果是可编辑的草稿，不是一张只能看的图。窗口底部有三个动作：

- **表格**——把这块内容重新识别成 Markdown 表格，粘进文档就是表格，不用手敲；
- **翻译**——选好目标语言一键翻译，结果直接替换正文，可以继续改；
- **AI 整理**——修错字、把被硬断开的行接回去、恢复段落和缩进、代码保留格式。

后两项需要一点配置：翻译内置了免费接口，第一次用会提示文字将发送到第三方服务（不同意就一个字节都不发），也可以在设置里填自己的翻译接口；AI 整理需要填一个 OpenAI 兼容的接口地址和 Key，Key 存在 Windows 的凭据加密里，不写进配置文件。

典型用法：截一张英文报错 → 识别 → 翻译 → 复制，全程不离开那个小窗口。

## 剪贴板历史

文本、富文本、图片、文件都能记。相同内容自动去重合并，可以搜索、收藏、加标签，也能按来源程序筛。

粘贴时按目标程序回填原格式——在 Word 里粘回富文本、保留格式，在代码编辑器里粘纯文本，不用每次手动"只保留文本"。

`Alt+V` 是顺序粘贴：连续复制五条，再连按五次，按复制顺序依次吐出。填表单、抄多行配置的时候特别省事。

历史记录用 Windows 的 DPAPI 加密落盘，绑定当前系统账户，把文件拷到别的账户也解不开；某些程序（比如密码管理器）可以配置成完全不记录。

## 鼠标手势

按住右键划动就能执行操作：八个方向加多笔组合，比如 `↗` 最大化、`↙` 最小化、`→←↓` 打开剪贴板。

规则可以按程序分组——只在浏览器里生效、或者对某个程序单独一套。也支持滚轮修饰和屏幕边缘滚动，划动时会在屏幕上回显你按的键，方便记。

顺带解决了一个小麻烦：不少网页和程序会劫持右键菜单，但"按住右键划动"跟点击不冲突，照样能用。

## 录屏与 GIF

框选区域就能录，输出 MP4 或 GIF。可选摄像头画中画（或并排）、麦克风与系统声音，录制前有倒计时。

给同事演示一个操作、给文档配一段动图，不用再开一个专门的录屏软件——GIF 直接就是能贴进文档和聊天窗口的格式。

## 图片转换与图标提取

这两块走资源管理器的右键菜单，选中文件就能转：

- **格式转换**：JPG、PNG、WebP、GIF、BMP、TIFF、ICO 互转，可批量；
- **图标提取**：从 exe、dll、lnk、msi、apk、ipa、dmg、deb、rpm、AppImage 等文件里取出图标，输出 PNG、ICO 或全尺寸图集。

做图标、找素材、给快捷方式换个图标的时候，这两个功能比打开一堆在线工具顺手，而且完全本地处理。

## 多平台图床

支持 GitHub 仓库、S3 兼容存储、WebDAV、自定义 HTTP 接口四类。上传、浏览历史、复制链接都在一个页面里，截图工具条里也能直接上传。

链接格式可选直链、Markdown、HTML、BBCode，写博客、发帖、贴论坛的时候省掉一步手动转换。

## 顺手塞进去的一页：开发工具

设置面板里还有一页小工具：JSON 格式化与压缩、编码转换（Base64 / URL / Unicode）、时间戳互转、正则测试、哈希、UUID 生成、颜色格式转换、JWT 解析。

纯本地计算，不联网、不落盘。有时候只是想把一段 JSON 排个版，不值得为它再开一个网站。

## 上手

到官网或 GitHub Releases 下载 `zhuxia-<版本>-win-x64.zip`，解压到任意目录，双击 `zhuxia.exe`。

第一次启动会请求管理员权限（全局手势、部分硬件指标、修改防火墙规则需要），然后问两件事：任务栏显示成细栏还是悬浮卡片、要不要用驻匣接管 `Win+V`。不接管也能用 `Alt+C` 打开剪贴板，不影响使用。

常用热键：

| 操作 | 热键 |
| --- | --- |
| 截图 | `Alt+A` |
| 剪贴板面板 | `Alt+C` |
| 顺序粘贴 | `Alt+V` |
| 面板内搜索 | `Alt+F` |
| 图床上传 | `Ctrl+Shift+U` |
| 鼠标手势 | 按住右键划动 |

所有热键、手势规则都能在设置面板里改。

## 边界，说在前面

- **系统**：Windows 10 / 11 x64。macOS 和 Linux 不支持，也不打算支持。
- **权限**：需要管理员。这是真实的代价，不是"零权限"工具；如果不需要手势和防火墙相关功能，可以关掉对应模块。
- **联网**：截图、剪贴板、格式转换、图标提取、录屏、开发工具全部本地完成。会联网的只有四处，而且都要你主动配置或触发——检查更新、公网 IP 与延迟探测、图床上传、Clash 流量读取。翻译是唯一会把内容发给第三方的功能，所以第一次用会明确询问。
- **账号**：没有。不需要注册，没有遥测，没有广告。
- **状态**：当前 0.0.3，预览版。主体功能每天都在用，但版本号最后一位不是 0 就代表还会变，也可能存在我没覆盖到的场景。
