# 图床（imgbed）

## 功能

- 多平台：GitHub、S3 兼容、WebDAV、自定义 HTTP。
- 三个页面：上传、图片浏览、平台设置。
- 上传来源：文件选择、拖拽、剪贴板图片、截图工具条快捷上传（`Ctrl+Shift+U`）。
- 图片处理：转 WebP、最大边长、质量、EXIF 转正、透明区压平。
- 路径模板：`{yyyy}` / `{MM}` / `{dd}` / `{name}` / `{ext}` 等日期与文件名变量。
- 浏览：本地上传历史 + 远端目录（平台支持时），缩略图、搜索、排序、复制链接、删除。
- 密钥：DPAPI 加密保存，面板不回显明文。

## 上传流程

```text
选择文件 / 拖拽 / 剪贴板
  → 去重与格式识别
  → 可选 WebP 转换与尺寸限制
  → 按平台生成路径与请求
  → 上传（失败重试/错误汇总）
  → 写本地历史 + 复制链接
```

- 队列串行上传，避免大量并发触发平台限流。
- 每个平台独立配置；字段按平台能力动态渲染。
- 上传失败保留条目与错误信息，可重试，不静默丢弃。

## 平台适配

- **GitHub**：Contents API，按分支/目录写入；适合公开仓库图床。
- **S3 兼容**：SigV4 签名，支持自定义 Endpoint、Region、Bucket、路径风格。
- **WebDAV**：PUT/MKCOL/PROPFIND，支持基础认证。
- **自定义 HTTP**：用户提供上传地址、方法、字段名与响应中链接的 JSON 路径。

## 存储

```text
<exe>/imgbed/
  history.dat     上传历史与远端条目缓存
  thumbs/         缩略图缓存
  secrets.dat     DPAPI 加密的密钥
```

- 历史跨平台共享，记录平台、远端路径、链接、大小、时间、格式。
- 缩略图按需生成，面板按视口懒加载，切页释放。

## 边界

- GitHub 对大文件与高频提交有限制；单文件建议不超过平台上限。
- 自定义 HTTP 需要用户自行保证接口兼容与鉴权。
- 私有仓库/需要鉴权的图片，浏览时由后端取字节；公开链接直接加载。
- 图床可用性取决于网络与平台策略，失败不会影响本地文件。
