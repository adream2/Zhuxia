# 鼠标手势（gesture）

## 功能

- 按住右键（或中键）划动，识别 8 方向与多笔组合。
- 通用规则 + 按程序分组：同一手势在不同程序里执行不同动作。
- 三级作用域：全局、分类、指定程序。
- 滚轮修饰：按住手势键滚动，匹配另一套规则；支持每格执行或松手执行一次。
- 边缘滚动：屏幕四边滚轮触发音量、亮度、切标签、切程序。
- 按键回显：屏幕角落显示当前按键，组合键合并为一颗键帽。
- 轨迹与动作名提示：命中/未命中两套颜色，可配置时长与线宽。
- 暂停、排除程序、全屏/桌面禁用、单击重放。

## 默认开关

| 项 | 默认 | 说明 |
|---|---|---|
| 手势 | 开 | 按住右键划动 |
| 中键手势 | 关 | 避免抢中键粘贴/自动滚动 |
| 全屏时禁用 | **开** | 只认真·全屏；最大化窗口不算（判据见 `zx-ui::window::foreground_fullscreen`，先看 `IsZoomed`） |
| 桌面上禁用 | 关 | |
| 边缘滚动·左 | **开** | 音量 ± |
| 边缘滚动·右 | **开** | 亮度 ±（DDC/CI） |
| 边缘滚动·上/下 | 关 | 会抢页面滚轮，要用手动开 |

## 默认手势（12 条）

| 方向 | 动作 |
|---|---|
| `→` / `←` | 前进 / 后退 |
| `↓→` / `↓←` | 关闭窗口 / 关闭相似窗口 |
| `↗` / `↙` | 最大化还原 / 最小化 |
| `→↙→` | 排除当前程序 |
| `↙↘↙` | 截图 |
| `↓→↓` | 编辑 hosts |
| `→←↓` | 打开剪贴板 |
| `↓→↑` | 打开图床 |
| `←↓→` | 打开开发工具 |

## 技术路线

- 全局低级鼠标钩子 `WH_MOUSE_LL`，在钩子线程内只做轻量判定与事件入队。
- 手势线程维护会话状态机：Start → Move →（Wheel）→ End；移动事件按距离采样。
- 识别器支持 Exact（8 方向）与 Cardinal（首笔 8 方向、后续上下左右）两遍匹配，
  先高保真、再低保真。
- 匹配在松手时执行，画到一半不会提前触发；滚轮修饰可锁定方向串。
- 覆盖层是覆盖虚拟桌面的透明分层窗口，鼠标穿透；轨迹用 `PostMessage` 合并重绘。
- 动作分发：快捷键、窗口控制、运行程序、音量、内置动作（宿主注入）。
- 边缘滚动在钩子内直接判定并吞掉滚轮，不经过手势会话。
- 按键回显使用独立 `WH_KEYBOARD_LL`，注入事件带标记，不回显自身。

## 配置

`settings.yaml → gesture`：

- `enabled` / `paused`、灵敏度、鼠标键、目标窗口策略；
- 轨迹颜色/线宽/提示时长、排除程序、全屏/桌面禁用；
- `rules`（通用规则）、`groups`（程序分组）、`edges`（边缘滚动）、`key_echo`（按键回显）。

规则改动 1 秒内热重载；`enabled` 只在启动时读取，运行期暂停用 `paused`。

## 边界

- 以管理员权限运行的程序可能收不到普通权限注入的按键。
- 全屏独占游戏、安全桌面、UAC 提示界面不响应。
- 高 DPI 多屏下轨迹按物理像素绘制；混合 DPI 时提示位置以光标所在屏为准。
- 手势键与程序自身右键操作冲突时，可在排除列表里禁用。
