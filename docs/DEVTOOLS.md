# 开发者工具箱（devtools）

## 功能

- JSON 格式化 / 压缩 / 校验。
- Base64、URL、HTML 实体编码解码。
- 时间戳与日期互转（秒/毫秒、本地/UTC）。
- 正则测试与替换。
- MD5 / SHA-1 / SHA-256 / SHA-512。
- UUID 生成（v4）。
- 颜色格式转换（HEX / RGB / HSL）与取色。
- JWT 解码与过期检查。

## 技术路线

- 纯前端页面，运行在设置面板的 WebView2 中。
- 所有计算在本地完成：不联网、不落盘、不写 `settings.yaml`。
- 没有对应的 Rust command；关闭面板即释放。
- 输入/输出区分离，错误以行内提示显示，不阻塞其他工具。

## 边界

- JWT 只解码，不校验签名。
- 哈希用于校验/调试，不用于密码存储。
- 大文本受 WebView 内存限制，超大 JSON 可能卡顿。
