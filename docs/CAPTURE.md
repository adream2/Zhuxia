# 截图与贴图（capture）

## 功能

- 选区、窗口、全屏三种入口；支持多显示器与跨屏选区。
- 标注：矩形、椭圆、箭头、画笔、马赛克、文字、序号、高亮、裁剪。
- 美化：背景、圆角、边框、阴影、水印、内边距，实时预览。
- 拼接：多张截图按横/纵/网格拼接。
- 长截图：选区内滚动，按行特征对齐后拼接。
- OCR：系统自带 `Windows.Media.Ocr`，本地识别，不联网、不下载模型。
- 贴图：截图钉在桌面最上层，滚轮缩放、双击关闭。
- 输出：PNG 写盘 + 剪贴板（PNG 与 DIB 双格式）。

## 交互流程

```text
热键 / 托盘 / 工具条
  → 抓取虚拟桌面（一次 BitBlt 到 32bpp DIB）
  → 全屏分层覆盖层：变暗、选区、放大镜、窗口轮廓
  → 松手进入编辑态：标注、工具条、样式面板
  → 复制 / 保存 / 贴图 / OCR / 长截图 / 拼接 / 录屏
```

- 覆盖层是 `WS_EX_LAYERED` 分层窗口，按虚拟桌面坐标绘制，多屏不需要拼接 tile。
- 标注保存为**数据**（图形列表），每次重绘重建；撤销/重做只操作列表，不存像素快照。
- 选区手柄支持越过对边翻转；拖动、缩放、键盘微调共用同一套命中测试。

## 技术路线

- 抓屏：GDI `BitBlt` + `CAPTUREBLT`，覆盖分层窗口与硬件加速层；不引入 D3D11/DXGI。
- 绘制：`zx-ui::Canvas`（DIB + GDI+），文字/图标/圆角/阴影统一走设计 token。
- 长截图：不注入页面、不接管滚轮；按固定间隔抓同一区域，用行签名找滚动位移。
- OCR：WinRT `SoftwareBitmap` → `OcrEngine::RecognizeAsync`，结果按行/词回填。
- 贴图：无边框置顶窗口 + 自绘标题区，滚轮缩放、双击关闭。
- 录屏入口：选区交给 `record` 模块，覆盖层先销毁，避免被拍进帧。

## 文件与输出

```text
<截图目录>/截图_yyyyMMdd_HHmmss.png
```

- 默认保存目录可配置；文件已存在时自动加 `-2`、`-3` 后缀，不覆盖。
- 复制到剪贴板同时写 `PNG` 与 `CF_DIB`，兼容 Office、聊天工具与旧程序。

## 边界

- 受 DRM/安全桌面保护的窗口可能抓黑。
- 长截图依赖页面可滚动；固定表头/懒加载页面可能拼接错位。
- OCR 语言取决于系统已安装的语言包。
- 美化与标注在导出时栅格化；原始选区不保留。
